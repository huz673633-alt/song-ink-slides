# 宋韵水墨视觉与版式

## 构图

- 封面及转场让山石落在画面右下，远山退入雾，标题放在左上或中上清淡区。画面只设一个视觉重心。小面积朱砂可用在章节字标、短线或印记，三者选其一。
- 正文优先用平整纸色。若需要保留淡墨，让画面沿底边或外侧展开，避开正文和图注。可选用带墨痕的封面构图时，仅在墨面足够均匀的区域叠放原生浅色标题。
- 有真实器物图时，给器物完整轮廓和呼吸空间。单件图文可以左图右文，两件对照用同一视线高度和相近的图像区，图注放到各自图片下方。

## 色与字

| 用途 | 色值 |
| --- | --- |
| 暖纸底 | `#F7F4EC` |
| 墨色标题与正文 | `#252B27` |
| 青瓷灰绿辅助文字 | `#41584F` |
| 图注灰 | `#555D56` |
| 朱砂强调 | `#9D3E31` |
| 细分隔线 | `#B7BDB0` |

模板是 16:9。标题为宋体，正文用微软雅黑。其他环境优先选本机可用的宋体类与中文无衬线字体，换字体后重新检查断行。正文通常约 18–21 pt，图注约 12–13 pt，投影时可适度放大。长段文字优先拆页或改版面。

## 十一种页面

| 版式 | 放置内容 |
| --- | --- |
| 封面 | 短标题、一行副题、必要时加一个系列名 |
| 导览 | 三个观察角度或章节，序号、标题和说明分列 |
| 章节 | 章序、短标题和一句引语 |
| 单件图文 | 大图、紧邻的馆藏图注、两三句可见细节 |
| 两件对照 | 同一问题下的两张图，各自注明年代、藏地及编号 |
| 文献导读 | 左侧分为短引文、解读和出处，右侧保留山水。没有引文时，可改为简短的背景说明和要点 |
| 时间线 | 横向轴线上放 3–5 个节点，每个节点含时间、事件名和短说明 |
| 流程图 | 墨色圆节点和方向箭头串起动作，步骤名与说明放在节点下方 |
| 大图标注 | 主图居中，标注分列两侧，引线和落点对应图中可见的细节 |
| 数据图表 | 暖纸底配青瓷灰绿横向条形图，显示类别、数值、单位和来源 |
| 结尾 | 一句与实物或主题相关的总结 |

### 文献导读

引文和解读各用一个可换行的文本框，右侧装饰区留白。投影版每段以约两三行为宜。长引文可按完整语意拆页，出处随引文保留。正文贴近浅色区域，避免与山石叠压。

### 时间线

时间标签统一精度，事件标题和说明垂直对应各自的节点。节点等距时，如果日期间隔不同，在图下注明间距只表示先后。需要表达实际时长时，按时间比例布置；年代有疑问时用原资料给出的范围或近似表述。操作步骤可沿用节点结构，把日期改为步骤编号。

### 流程图、大图标注与数据图表

- 流程图用动词开头写步骤名，每步留一行说明。主线从左到右，分支有明确条件时另设节点。步骤太多时可按阶段拆页。
- 大图优先保住物体轮廓与标注空间。每条引线只指一个细节，尽量水平且彼此不交叉，换图时重新定位落点。梅枝、竹叶和印记等装饰留在画面边角，避免贴近引线或占据照片主体。
- 条形图用零基线和统一尺度表达数量，按量值或类别自然顺序排列。图表标签用原生数据标签，保留来源、统计口径和单位。若要解释连续时间变化，可改用原生折线图。用实际数据替换模板里的四组演示值。

图表布局参考 [Flourish 的横向条形图示例](https://flourish.studio/blog/different-types-of-charts/#2-bar-and-column-charts-compare-categories)。在 PowerPoint 中可通过 [图表设计 → 编辑数据](https://support.microsoft.com/en-gb/powerpoint/change-the-data-in-an-existing-chart) 替换类别和数值。
